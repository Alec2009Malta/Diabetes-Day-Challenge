# Diabetes Day Challenge

A small browser game for a CREST Gold project about the challenges faced by parents and children managing Type 1 diabetes.

The game helps children practise safe everyday decisions in situations such as school, sport, hypos, illness, snacks, and oral health. It is designed as an educational support tool and does not replace a personal diabetes care plan or professional medical advice.

## Files

- `index.html` - the web page
- `styles.css` - the design
- `script.js` - the game logic and scenarios

## How to test it

Open `index.html` in a web browser.

## How to publish on GitHub Pages

1. Go to https://github.com and sign in.
2. Click **New repository**.
3. Name it `diabetes-day-challenge`.
4. Keep it **Public**.
5. Click **Create repository**.
6. Upload these files:
   - `index.html`
   - `styles.css`
   - `script.js`
   - `README.md`
7. Go to **Settings**.
8. Click **Pages** in the left menu.
9. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
10. Click **Save**.

After a minute or two, GitHub will give you a public link like:

`https://yourusername.github.io/diabetes-day-challenge/`

## Suggested report wording

After developing the parent checklist and child-friendly flashcards, I extended the project into an online scenario-based game. The game allows children to practise diabetes-related decisions in everyday contexts such as school, sport, illness, hypoglycaemia management, snacks, and oral health. It was designed to support confidence, routine recognition, and communication with adults, rather than to replace professional clinical advice.

## Safety wording

This game is an educational activity. Families should always follow their own diabetes care plan and advice from healthcare professionals.
